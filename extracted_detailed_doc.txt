1. Executive Summary
The document describes a full-stack Event Management Platform that enables users to create,
manage, search, and book events with integrated payments and real-time notifications. It follows a
MERN architecture (MongoDB, Express.js, React.js, Node.js) with a monorepo structure and is designed
for three user roles: Admin, Organizer, and Attendee.
The system is production-grade with Stripe payments, Cloudinary media hosting, Socket.io real-time
features, QR-code ticketing, and CI/CD deployment to Vercel + Render.

10.2 Cloudinary Image Pipeline
Upload: Multer parses multipart → stream to Cloudinary
Transform: Auto-resize to 1200×630 on upload
Store: Save secure_url  + public_id  in Event document
Cleanup: Delete old image from Cloudinary on event image update

10.3 Socket.io Real-time Architecture
Socket server attached to same HTTP server
JWT authentication middleware on socket handshake
Room-based: each event = one room ( event:{eventId} )
Events emitted: ticket:updated , booking:confirmed , notification:new
